07 — OWASP

Controles e considerações de segurança.

A arquitetura atual é uma landing page estática. Por isso, alguns riscos são mitigados por design ou não são aplicáveis enquanto não houver backend. Mas apliquei OWASP em aplicações reais em experiências profissionais.

A01 Broken Access Control Considerado / arquitetura estática
A02 Cryptographic Failures HTTPS e minimização de dados
A03 Injection Validação e ausência de execução dinâmica
A04 Insecure Design Security by Design
A05 Security Misconfiguration Headers e hardening documentados
A06 Vulnerable Components Dependências minimizadas
A07 Identification & Authentication Não aplicável sem autenticação
A08 Software & Data Integrity Versionamento e controle
A09 Logging & Monitoring Considerado para futuras integrações
A10 Server-Side Request Forgery Não aplicável ao frontend estático
